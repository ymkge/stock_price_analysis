# 株価分析プロジェクト (stock_price_analysis)

このリポジトリは、日本の株式市場に上場している銘柄のデータを取得・分析するための一連のJupyter Notebookを含んでいます。主な目的は、特定の条件に基づいて割安な高配当銘柄をスクリーニングすることです。

## プロジェクトの概要

本プロジェクトは、複数のNotebookスクリプトで構成されており、それぞれが特定の役割を担っています。処理の全体的な流れは以下の通りです。

1.  **上場銘柄リストの取得**: 日本取引所グループ（JPX）のウェブサイトから最新の上場企業一覧を取得します。
2.  **財務・株価データの収集**: `yahooquery`ライブラリを使用し、全上場銘柄の財務データ（ROE、自己資本比率など）および株価関連指標（時価総額、配当利回り、配当性向など）を非同期で効率的に一括取得します。
3.  **データの中間保存**: 取得した膨大なデータを、分析しやすいように2つのCSVファイル (`company_metrics.csv`, `company_financial_info.csv`) に整理して保存します。
4.  **割安銘柄のスクリーニング**: 保存したCSVデータを基に、以下のような独自の基準で割安かつ財務健全な高配当銘柄を絞り込みます。
    -   配当利回り (3% ~ 6%)
    -   配当性向 (50%以下)
    -   時価総額 (1000億円以上)
    -   ROE (自己資本利益率, 8%以上)
    -   自己資本比率 (30%以上)
    -   財務安定性 (売上・利益の安定、過去10年の非減配)
5.  **結果の出力**: スクリーニングを通過した有望な銘柄のリストを `company_match_condition.csv` として出力します。

また、個別銘柄の詳細なテクニカル分析（RCI、フィボナッチ・リトレースメントなど）を行うためのNotebookも含まれています。

## 各ファイルの役割

-   `株式割安銘柄取得データ.ipynb`
    -   このプロジェクトのメインとなるNotebookです。
    -   JPXからの全銘柄リスト取得、`yahooquery`による財務・株価指標の一括取得、CSVファイルへの保存、および割安銘柄のスクリーニングという一連のパイプライン処理を実行します。

-   `get_stock.ipynb`
    -   `yfinance`ライブラリを使用し、ユーザーが指定した個別銘柄の株価、主要指標（PER, PBR）、テクニカル指標（RCI、フィボナッチ・リトレースメント）を詳細に分析・表示します。インタラクティブに銘柄コードを入力して分析する機能も含まれています。

-   `stock_code_acquisition.ipynb`
    -   Yahoo!ファイナンスの時価総額ランキングをスクレイピングし、時価総額が3000億円以上の企業リスト（銘柄コード、銘柄名、時価総額）を抽出します。

-   `scraping.ipynb`
    -   `stock_code_acquisition.ipynb` のためのデバッグ用スクリプトです。Yahoo!ファイナンスからスクレイピングした生のHTMLテーブルデータを `raw_scraping_data.csv` に保存し、データ構造の確認を容易にすることを目的としています。

-   `*.csv`
    -   `raw_scraping_data.csv`: スクレイピングの生データ（デバッグ用）。
    -   `company_metrics.csv`: 全銘柄の最新の主要指標データ。
    -   `company_financial_info.csv`: 全銘柄の時系列財務データ。
    -   `company_match_condition.csv`: スクリーニング条件に合致した銘柄リスト（最終成果物）。
